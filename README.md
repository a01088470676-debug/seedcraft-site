## 새 플러그인 추가하기

`index.html`의 `<div class="products">` 안에 상품 카드 템플릿 주석이 있습니다. 그 블록을 복사해서 아이콘/배지/이름/설명/가격/링크만 바꿔 넣으면 새 카드가 추가됩니다.
