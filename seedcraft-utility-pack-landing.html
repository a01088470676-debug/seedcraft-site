SeedCraft 서버 유틸리티팩

현상금, 취침 스킵, 오늘의 미션, 보호 표지판, 동맹 — 서로 의존성 없는 5개의 독립 실행형 유틸리티 플러그인입니다. 필요한 것만 골라서 설치하거나 제거할 수 있고, 전부 자체 config.yml로 수치와 문구를 조절합니다.

💰 SMBounty (현상금)

SMBounty-1.0.0.jar

플레이어에게 현상금을 걸고, 처치 시 자동으로 지급합니다. 현상금 최대치는 config.yml에서 자유롭게 조절합니다.

명령어설명
/현상금 <플레이어> <금액>현상금 등록 (누적 가능)
/현상금관리 reload설정 다시 불러오기

🌙 SMNightSkip (야간 스킵)

SMNightSkip-1.0.0.jar

일정 비율 이상이 침대에 누우면 보스바/타이머 표시 후 자동으로 아침이 됩니다. 베타 버전 — 프리미엄 제한 없이 전 기능 무료 배포.

명령어설명
(자동)침대에 눕는 것만으로 작동, 별도 명령어 없음
SMNightSkip 받기

🎯 SMDailyMission (오늘의 미션)

SMDailyMission-1.0.0.jar

플레이어마다 매일 무작위 미션 1개가 배정됩니다. 완료 시 폭죽 + 경험치 보상, 가장 먼저 깬 사람은 "오늘의 왕".

명령어설명
/미션오늘의 미션 진행 상황 확인
SMDailyMission 받기

🪧 SMProtectionSign (보호 표지판)

SMProtectionSign-1.0.0.jar

표지판에 [보안]을 적으면 그 구역이 소유자 전용으로 보호됩니다. 청크 전체 또는 반경 지정이 가능합니다.

명령어설명
([보안] 표지판)표지판 설치만으로 구역 보호 발동
/보호관리 reload설정 다시 불러오기
SMProtectionSign 받기

🤝 SMAlliance (동맹)

SMAlliance-1.0.0.jar

신뢰하는 플레이어를 동맹으로 등록합니다. 동맹끼리는 서로 PvP 피해를 주지 못하도록 막을 수 있습니다(config로 on/off).

명령어설명
/동맹 추가 <닉네임>동맹 등록
/동맹 제거 <닉네임>동맹 해제
/동맹 목록내 동맹 목록 확인
SMAlliance 받기

🧩 SMPremiumFramework (프리미엄 기반)

SMPremiumFramework-1.0.0.jar
인프라 · 지금은 아무것도 제한하지 않음

위 5개 플러그인이 나중에 프리미엄 기능을 붙일 때 공통으로 쓸 라이선스 확인 뼈대입니다. 지금은 어떤 플러그인도 이 프레임워크에 의존하지 않으며, 설치 여부와 무관하게 위 5개는 전부 정상 동작합니다.

HOW TO INSTALL

설치는 이렇게 진행해요

결제나 로그인이 필요 없습니다. 원하는 jar만 받아서 넣으면 끝입니다.

01

필요한 jar 다운로드

위에서 원하는 플러그인만 골라 받거나, "전체 한번에 받기"로 5종 세트를 받으세요.

02

서버 plugins 폴더에 넣기

jar 파일을 서버의 plugins/ 폴더에 넣습니다.

03

서버 재시작

재시작하면 자동으로 config.yml이 생성됩니다. 수치/문구를 수정한 뒤 각 플러그인의 reload 명령어로 바로 반영할 수 있습니다.

FAQ

자주 묻는 질문

5개를 다 설치해야 하나요?

아니요. 전부 독립적이라 필요한 것만 골라 설치해도 되고, 나중에 하나씩 추가/제거해도 다른 플러그인에 영향이 없습니다.

보호 표지판과 동맹을 같이 쓰면 자동으로 연동되나요?

지금은 아닙니다. 보호 표지판은 소유자 전용 잠금만 제공하고, 동맹은 별도의 PvP 피해 방지 기능만 제공합니다. 두 기능이 서로 몰라도 각자 정상 동작하도록 의도적으로 분리했습니다.

나중에 유료(프리미엄) 버전이 나오나요?

일부 플러그인은 프리미엄 전환 후보입니다(각 플러그인 README 참고). 지금 받으신 버전이 계속 무료로 동작하며, 프리미엄은 별도 애드온으로 나중에 추가될 예정입니다.
