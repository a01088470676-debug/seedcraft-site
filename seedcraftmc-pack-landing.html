팩에 포함된 플러그인

Free와 Pro는 서로 다른 별도 플러그인이라, 둘 중 하나만 설치하면 됩니다. Pro는 Free 기능을 모두 포함하고 그 위에 추가 기능이 붙습니다.

🏗️ BuildBattleStudio

빌드 배틀 진행을 자동화하는 플러그인. 플롯 생성부터 카운트다운, 투표까지 명령어로 처리합니다. Free 버전 명령어는 전부 buildbattle.admin 권한이 필요합니다.

FREE
명령어설명
/bb create <이름> <플롯수> <플롯크기>서 있는 위치 기준으로 플롯 N개 자동 생성(벽+바닥)
/bb start <이름> <초>카운트다운 시작, 종료 시 벽 철거
/bb remove <이름>세션 제거 + 벽 철거(정리)
PRO
명령어권한설명
/bb create <이름> <플롯수> <플롯크기>admin플롯 자동 생성
/bb start <이름> <초>admin카운트다운 시작, 종료 시 불꽃놀이 공개 + 투표 창 자동 오픈
/bb remove <이름>admin세션 제거
/bb cam <이름> <플롯번호> [반경] [속도]admin해당 플롯 궤도 관전 카메라 시작
/bb camstop누구나궤도 카메라 종료
/bb vote <이름> <플롯번호> <1-10>누구나 (투표 시간에만)플롯에 점수 투표 → 투표 종료 시 자동 우승 발표

※ <이름>은 세션 식별용 문자열(예: round1), <플롯번호>는 /bb create 순서대로 매겨진 0부터 시작하는 인덱스입니다.

FAQ

자주 묻는 질문

Free와 Pro를 같이 설치해도 되나요?

안 됩니다. Hardcore100Days/Pro, BuildBattleStudio/Pro는 각각 서로 다른 플러그인이라 같은 서버엔 Free 또는 Pro 중 하나만 설치해야 합니다.

두 플러그인을 따로 사고 싶어요.

지금은 팩 단위로만 판매하고 있습니다. 개별 판매가 필요하시면 디스코드로 문의해주세요.

환불이 가능한가요?

파일 전달 전에는 언제든 환불 가능합니다. 파일 전달 후에는 정상 작동하지 않는 경우에 한해 환불해드립니다.

구매 전 궁금한 점이 있나요?

디스코드에서 개발자에게 바로 물어보세요.
